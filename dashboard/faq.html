🚀 Installation & General Operation 5 questions

Setup How do I install and start XAMPP?

XAMPP for Windows is available as an installer executable or a portable ZIP package:

  • Installer: The recommended method. Runs the setup wizard and configures shortcuts under Start > Programs > XAMPP.
  • ZIP/7zip: Extract into your desired drive root (e.g. C:\xampp). If placed in another folder, run setup_xampp.bat once to update relative path references.

The universal control interface is the XAMPP Control Panel:

C:\xampp\xampp-control.exe

You can also use standalone batch scripts in C:\xampp to start and stop services directly:

  • apache_start.bat / apache_stop.bat
  • mysql_start.bat / mysql_stop.bat
Verification How can I test that everything is working?

Open your browser and navigate to either:

http://localhost/   or   http://127.0.0.1/

You should see the active XAMPP Dashboard. From here you can test PHP by visiting /dashboard/phpinfo.php or database access at /phpmyadmin/.

Files Where should I place my web projects and PHP files?

The default document root for all web documents is:

C:\xampp\htdocs

For example, if you place a project folder named waterbillingsystem in C:\xampp\htdocs\waterbillingsystem, it is accessible in your browser at:

http://localhost/waterbillingsystem/

Standard index files such as index.php or index.html are automatically served when browsing to a folder URL.

Services How can I install Apache or MySQL as a Windows service?

Installing a component as a service allows it to start automatically when Windows boots:

  1. Launch XAMPP Control Panel with Administrator privileges (Right-click > Run as administrator).
  2. Click the checkbox with the red X next to Apache or MySQL.
  3. Confirm installation when prompted; the icon changes to a green checkmark.

Alternatively, run the dedicated service scripts with administrator rights:

Apache: C:\xampp\apache\apache_installservice.bat
MySQL:  C:\xampp\mysql\mysql_installservice.bat
Uninstall How do I cleanly uninstall or relocate XAMPP?

Always back up your C:\xampp\htdocs and C:\xampp\mysql\data folders before uninstalling:

  • Installer version: Run C:\xampp\uninstall.exe to unregister services and clean registry entries.
  • ZIP/Portable version: Stop all running servers in the control panel, uninstall any registered Windows services, and delete the C:\xampp directory.
  • Relocating XAMPP: If moving to another drive or folder, run C:\xampp\setup_xampp.bat to update internal path configurations.

🌐 Apache & Port Troubleshooting 4 questions

Port 80 Why won't Apache start? (Port 80 / 443 already in use)

If Apache fails with make_sock: could not bind to address 0.0.0.0:80, another program is already using port 80 or 443.

Common culprits and fixes:

  • IIS (World Wide Web Publishing Service): Open Windows Services (services.msc), locate World Wide Web Publishing Service, stop it and set Startup type to Disabled.
  • Skype: Go to Skype Settings > Advanced > Connection and disable "Use port 80 and 443 as alternatives".
  • Change Apache's Port: If port 80 cannot be freed, open C:\xampp\apache\conf\httpd.conf and change: 
    Listen 8080
ServerName localhost:8080
    Then access your server at http://localhost:8080/.
Windows 10/11 How do I disable Microsoft IIS to free up port 80?

On Windows 10 and 11, Microsoft IIS services often claim port 80 by default:

  1. Press Win + R, type services.msc, and hit Enter.
  2. Scroll down to find World Wide Web Publishing Service.
  3. Right-click and select Properties.
  4. Click Stop, then change Startup type to Disabled.
  5. Click OK, then start Apache in the XAMPP Control Panel.
Performance Why is CPU usage high for Apache? (AcceptEx errors)

If you see Child: Encountered too many AcceptEx faults in C:\xampp\apache\logs\error.log, Windows network stack filters are timing out.

Solution: Open C:\xampp\apache\conf\extra\httpd-mpm.conf (or httpd.conf) and add:

AcceptFilter http none
AcceptFilter https none

Restart Apache to apply the change.

Assets Why are images or stylesheets sometimes failing to load?

On some Windows network drives or file shares, Apache's memory-mapped I/O can fail to deliver static assets cleanly.

Fix: Open C:\xampp\apache\conf\httpd.conf and add or uncomment these lines:

EnableSendfile off
EnableMMAP off

Restart Apache after modifying the file.

🗄️ MySQL, MariaDB & phpMyAdmin 4 questions

Engine Does XAMPP include MySQL or MariaDB?

Modern XAMPP releases ship with MariaDB as a 100% binary drop-in replacement for MySQL. All tools (including mysql.exe, mysqldump.exe, PHP's pdo_mysql and mysqli extensions, and phpMyAdmin) work identically without changes to your PHP code.

Security How can I set or change the MySQL root password?

By default in XAMPP, the MySQL root user has an empty password (no password).

To assign a root password, click Shell in the XAMPP Control Panel and run:

mysqladmin.exe -u root password "your_new_password"
Important for phpMyAdmin: After setting a root password, update C:\xampp\phpMyAdmin\config.inc.php by adding your password:
$cfg['Servers'][$i]['password'] = 'your_new_password';
phpMyAdmin How do I restrict or allow external network access to phpMyAdmin?

By default, phpMyAdmin is restricted exclusively to local connections (Require local) for security.

To inspect or modify access, edit C:\xampp\apache\conf\extra\httpd-xampp.conf:

<Directory "C:/xampp/phpMyAdmin">
    AllowOverride AuthConfig
    Require local
</Directory>

Never set Require all granted on production or public servers without strong password protection.

Custom MySQL Can I use an external MySQL server instead of the bundled one?

Yes. Simply do not start MySQL from the XAMPP Control Panel. In your application's database configuration (e.g. config.php), update $db_host, $db_port, and credentials to point to your custom MySQL or remote instance.

⚙️ PHP & Configuration Directives 5 questions

php.ini Why have changes in my php.ini not taken effect?

Two common reasons cause changes in php.ini not to appear:

  1. Apache was not restarted: Apache reads php.ini only once during initialization. Click Stop and then Start on Apache in the XAMPP Control Panel.
  2. Wrong file edited: The official active configuration file is: 
    C:\xampp\php\php.ini
    You can verify the active file anytime on the PHPInfo Dashboard under Loaded Configuration File.
Mail How do I configure PHP mail() with sendmail in XAMPP?

To enable PHP's mail() function on Windows, configure the included sendmail.exe utility:

  1. Open C:\xampp\php\php.ini, locate [mail function], and set: 
    sendmail_path = "\"C:\xampp\sendmail\sendmail.exe\" -t"
  2. Open C:\xampp\sendmail\sendmail.ini and configure your SMTP credentials: 
    smtp_server=smtp.gmail.com
smtp_port=587
smtp_ssl=tls
auth_username=your_email@gmail.com
auth_password=your_app_password
  3. Restart Apache in the XAMPP Control Panel.
Paths Where are the main XAMPP configuration files located?

Key configuration files across all XAMPP components:

Apache HTTP Config:    C:\xampp\apache\conf\httpd.conf
Apache SSL / VHosts:   C:\xampp\apache\conf\extra\httpd-vhosts.conf
PHP Configuration:     C:\xampp\php\php.ini
MySQL / MariaDB Config:C:\xampp\mysql\bin\my.ini
phpMyAdmin Config:     C:\xampp\phpMyAdmin\config.inc.php
Sendmail Config:       C:\xampp\sendmail\sendmail.ini
Extensions How do I enable PHP extensions (e.g. curl, intl, com_dotnet)?

To enable an extension:

  1. Open C:\xampp\php\php.ini in a text editor.
  2. Search for the extension directive (e.g. extension=intl or extension=com_dotnet).
  3. Remove the leading semicolon (;) if present.
  4. Save the file and restart Apache.

Check the loaded extension status in real-time via PHPInfo.

Uploads How do I increase upload size and memory limits?

To permit larger database imports in phpMyAdmin or large file uploads, edit C:\xampp\php\php.ini:

upload_max_filesize = 128M
post_max_size = 128M
memory_limit = 512M
max_execution_time = 300

Save and restart Apache.

🔒 Security, UAC & Windows Permissions 3 questions

Production Is XAMPP safe for production environments?
Notice: XAMPP is configured intentionally open for developer convenience and local experimentation. It is not hardened for public production deployment without explicit security adjustments.

Default security considerations:

  • The MySQL administrator (root) has no password by default.
  • The database daemon may be reachable via local network unless firewall-restricted.
  • phpMyAdmin and demo pages are configured for quick development access.

Always assign strong passwords and restrict network interfaces before exposing your system outside localhost.

Antivirus Help! My Antivirus flagged a file in XAMPP (False Positives)

Some security software flags server binaries or tools like xampp-control.exe. This is typically a false positive because the software binds local network sockets.

Recommended Antivirus adjustments:

  • Add an exception or whitelist for the folder C:\xampp.
  • Allow port 80, 443, and 3306 in your local Windows Defender Firewall.
  • Exclude localhost / 127.0.0.1 from web traffic real-time scanning to accelerate page loading.
UAC Why does User Account Control (UAC) block writing files in C:\Program Files?

Windows strictly restricts write access inside C:\Program Files without elevated permissions. If XAMPP is installed there, Apache and PHP scripts may fail to write logs, upload files, or edit configurations.

Recommendation: Always install XAMPP in a root folder such as C:\xampp, or right-click the XAMPP Control Panel and select Run as administrator.
